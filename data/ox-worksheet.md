# O/X 워크시트: 이 기록은 누가 볼 수 있어야 할까요?

> grill-me 인터뷰를 마친 뒤, 누가 무엇을 볼 수 있는지 헷갈릴 때 채웁니다.

아래는 가상의 가람중학교 수업 뒤 피드백 사이트에 남는 기록입니다. 과제 제출부터 피드백, 읽음 확인, 답글까지 핵심 장면에서 생기는 기록을 모았습니다. 각 기록을 학생 본인, 같은 반 다른 학생, 선생님의 입장에서 따져 봅니다.

**O** = 그 사람에게 보여도 됨, **X** = 그 사람에게 보이면 안 됨

| 사이트에 남는 기록 | 학생 본인 | 다른 학생 | 선생님 |
|---|---|---|---|
| 과제와 질문 | | | |
| 내가 쓴 글과 어려웠던 점 | | | |
| 선생님이 나에게 보낸 피드백 | | | |

## 채운 뒤 생각해 볼 것

1. "학생 본인" 칸과 "다른 학생" 칸의 답이 다른 줄은 어디인가요? 그렇다면 학생 화면은 모든 학생에게 같은 화면일까요, 그 학생 자신의 기록만 보이는 화면일까요?
2. "선생님" 칸에만 O가 있는 줄은 어디인가요? 그 기록은 어느 화면에만 두어야 할까요?
3. 찾은 기준을 한 줄로 적어 Codex에게 알려 주고, PRD의 "대상" 부분에 넣습니다.
