# 생각 노트

기존 방탈출과 분리된 사이트. 초등학생이 수업 후 배운 내용을 자기 말로 쓰고 선생님이 차수별로 피드백함.

## 기본 질문

1. 오늘 배운 내용을 자기 말로 설명해 보세요. (필수)
2. 오늘 수업에서 재미있었거나 흥미로웠던 점에 대해 이야기해 주세요! (선택)
3. 아직 헷갈리는 점은 무엇인가요? (선택)
4. 선생님들에게 바라는 점이 있나요? (선택)

선생님은 수업별로 질문을 수정할 수 있음. 이전 답변의 질문은 당시 내용을 보존함.

## 참여와 공개 범위

회원가입 없음. 학생은 수업 코드와 이름으로 최초 참여, 12자리 개인 확인 번호 자동 발급. 복귀 시 수업 코드와 확인 번호 필요. 학생 본인과 해당 수업 선생님만 답변과 피드백 열람. 선생님은 학생 확인 번호를 조회하여 분실한 학생 본인에게 알려 줄 수 있음. 교사 화면은 수업 비밀번호로 보호.

## 수정과 보관

답변은 1차·2차·3차 등으로 모두 보관. 선생님 피드백을 읽고 다시 제출 가능. 각 차수에 피드백 저장. 수업 삭제 전 확인창, 삭제 시 이름·번호·답변·피드백·접속 세션 함께 삭제.

## 화면

밝은 파란색과 흰색 노트, 큰 글씨와 입력창. 학생은 본인 답변과 피드백, 선생님은 학생 목록과 선택한 학생의 차수별 기록을 표시.
