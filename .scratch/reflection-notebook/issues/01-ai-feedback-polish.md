# 01: 생각 노트의 차수별 선생님 피드백을 AI로 다듬기

## 만들 내용

생각 노트의 학생별 1차·2차·3차 등 답변 기록에 있는 선생님 피드백 입력 칸에 ‘AI 피드백 다듬기’를 추가한다. 결과는 요청한 차수의 입력 칸에만 넣고, 선생님이 검토·수정한 뒤 기존 ‘피드백 보내기’ 또는 ‘피드백 수정 저장’을 눌러야 해당 차수에 저장되어 학생에게 보인다. 모든 차수의 답변과 피드백 보관 방식은 유지한다.

선행 티켓: 없음 — 생각 노트의 차수별 피드백 입력·저장 화면은 이미 구현되어 있다.

Status: implemented

## 완료 기준

- [ ] 선생님이 특정 학생·차수의 피드백을 다듬으면 그 입력 칸에만 결과가 들어가고, 자동 저장·공개 없이 검토·수정 후 기존 저장 버튼을 눌렀을 때만 해당 차수에 저장되고 학생에게 보인다.
- [ ] 생각 노트 화면은 `/api/feedback`만 호출하고, OpenAI 호출은 `api/feedback.js`에서만 수행하며 `OPENAI_API_KEY`와 `OPENAI_MODEL` 환경 변수를 사용한다. 화면 코드에는 비밀 키가 없다.
- [ ] 서버에서 교사 세션과 해당 수업·차수의 권한을 확인하고, OpenAI에 학생 이름·개인 확인 번호를 제외한 초안과 현재 차수의 학생 글만 전송한다. 피드백 본문에 학생 이름이 포함되면 제거하도록 안내하고 AI 전송을 막는다.
- [ ] 요청 중 중복 호출을 막고 직접 수정한 내용을 늦은 AI 결과로 덮어쓰지 않으며, 호출 실패 시 입력 내용과 저장된 피드백을 유지하고 재시도 안내를 보여 준다.

## 범위

`reflection-notebook-vercel2/app/Notebook.tsx`의 기존 `feedback[rev.id]` 편집 상태와 피드백 저장 버튼에 연결한다. Vercel 서버 함수 `api/feedback.js`를 추가하고 Next.js 배포에서 `/api/feedback` 경로가 올바르게 연결되는지 확인한다. 서버는 기존 `thought_session` 교사 세션과 해당 수업의 답변 소유 관계를 확인한다. 입력 길이·빈 입력과 호출 빈도를 제한하고 OpenAI 오류·환경 변수 누락에 비밀 키를 노출하지 않는다. Supabase 전환, 가람중학교 사이트 변경과 배포는 포함하지 않는다.

## Comments

생각 노트 명세와 현재 차수별 피드백 화면을 기준으로 작성했다. 생각 노트의 기존 티켓이 없어 다음 번호는 01이다. 구현 요청에 따라 생각 노트 코드에 반영했다. 이번 요청의 학생 글 전달과 중학교 2학년 눈높이 조건을 우선한다.

### 구현 및 확인

- `api/feedback.js`에 OpenAI 호출을 모으고 Next.js `/api/feedback` 경로를 연결했다.
- 차수별 기존 피드백 입력 칸의 저장 버튼 옆에 ‘AI로 다듬기’를 추가했다. 저장 컬럼 `feedback`과 기존 저장 동작은 유지했다.
- Node 내장 assert로 교사 권한, 수업 소유 관계, 이름·번호 제외, 입력 검증, 미설정 키·API 오류·출력 오류와 요청 제한을 확인했다. 테스트 도구는 설치하지 않았다.
- 실제 OpenAI 키는 입력하지 않았고 실제 모델 호출은 하지 않았다. 프로덕션 배포는 수행하지 않았다.

### 선생님이 직접 확인할 방법

1. 테스트 수업에서 학생으로 답변을 제출한다. 선생님으로 들어가 그 차수의 피드백 초안을 입력하고 ‘AI로 다듬기’를 누른다. 다른 차수의 입력 칸이 바뀌지 않는지 확인한다.
2. AI 결과가 ‘잘한 점:’과 ‘다음 걸음:’ 두 줄인지 확인한다. 아직 저장 버튼을 누르지 않은 상태에서 학생 화면에는 결과가 보이지 않아야 한다. 문장을 직접 고친 뒤 ‘피드백 보내기/피드백 수정 저장’을 누르면 그때 학생에게 보여야 한다.
3. 학생 글에 오개념을 쓰고 선생님 초안으로 과학 내용을 짚는다. AI가 오개념을 칭찬하거나 정답을 알려 주지 않고, 초안의 과학 내용을 다음 걸음 질문에 남기는지 검토한다. 학생 이름을 초안에 넣으면 이름을 빼라는 안내가 보여야 한다.
4. `OPENAI_API_KEY`를 설정하지 않은 환경에서 누르면 ‘AI 다듬기를 쓸 수 없습니다. 직접 써 주세요’가 보이고 초안은 남아야 한다. 그대로 직접 작성·저장할 수 있어야 한다. 응답 중 직접 수정한 내용도 늦은 AI 결과로 덮어쓰면 안 된다.

Vercel에서 확인하려면 feedback-site2의 Settings → Environment Variables에 `OPENAI_API_KEY`를 비밀 값으로 설정하고, 필요하면 `OPENAI_MODEL`을 설정한 후 생각 노트 폴더에서 다시 배포한다. 키는 채팅이나 화면 코드에 넣지 않는다.
