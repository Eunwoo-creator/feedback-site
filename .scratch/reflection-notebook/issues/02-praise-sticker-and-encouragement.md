# 02: 생각 노트에 칭찬 스티커와 선생님 응원 한마디 추가

## 만들 내용

선생님이 각 차수의 피드백에 칭찬 스티커 하나를 선택해 기존 피드백 저장 버튼으로 함께 전달할 수 있게 한다. 선생님이 수업 설정에서 오늘의 응원 한마디를 저장하면 해당 수업 학생 화면 맨 위에 표시한다. 학생별 모든 차수의 답변과 피드백 기록, 기존 AI 다듬기와 저장 버튼의 동작을 유지한다.

선행 티켓: 없음 — 기존 생각 노트 피드백과 수업 설정 화면을 확장한다. 01의 AI 피드백 다듬기와 함께 사용할 수 있어야 한다.

Status: ready-for-agent

## 완료 기준

- [ ] 선생님이 특정 차수에서 ‘없음/⭐ 멋진 생각/👏 수고했어요/🌱 한 걸음 성장’ 중 하나를 선택하고 기존 피드백 저장 버튼을 누르면 문장과 함께 저장되며, 해당 학생의 해당 차수에만 스티커가 보인다. 변경과 제거가 가능하고 다른 기록은 유지된다.
- [ ] 선생님이 수업 설정에서 120자 이내 응원 한마디를 저장하면 해당 수업의 모든 학생 화면에서 수업 제목 아래에 보인다. 빈 문자열을 저장하면 숨겨지고 다른 수업에는 영향을 주지 않는다.
- [ ] 스티커와 응원 한마디가 새로고침 후에도 남고 기존 기록은 기본값으로 정상 표시된다. 마이그레이션과 Supabase 실습 스키마 변경을 반복 적용해도 기존 답변·피드백이 사라지지 않는다.
- [ ] 학생의 변경 요청과 잘못된 입력은 서버에서 거절되고 문장은 안전한 일반 텍스트로 표시된다. 저장 전에는 학생에게 변경값이 보이지 않으며 실패 시 편집 내용을 유지한다. AI 다듬기는 스티커와 응원 문장을 바꾸지 않는다.

## 범위

`reflection-notebook-vercel2/app/Notebook.tsx`의 차수별 피드백과 기존 수업 설정·학생 화면을 확장한다. `/api/notebook`의 조회 응답과 피드백·수업 설정 저장, 데이터 타입과 실제 데이터베이스 마이그레이션을 함께 반영한다. `revisions.sticker`와 `lessons.encouragement`를 추가하고 `supabase/schema.sql`에도 멱등 컬럼 추가를 반영한다. 기존 교사 세션과 수업 권한 확인을 유지한다. 저장소 전환, 가람중학교 사이트 변경, 자동 AI 스티커 선택과 배포는 포함하지 않는다. 테스트 도구는 설치하지 않는다.
