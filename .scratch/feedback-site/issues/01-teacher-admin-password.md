# 01: 관리자 비밀번호로 선생님 화면 열기

## 만들 내용

선생님 화면을 관리자 비밀번호로 보호한다. 실습용 비밀번호 `teacher-demo`를 확인한 뒤에만 선생님 화면을 보여 준다. 확인 전에는 관리자 화면의 학생 글과 선생님만 보는 내용을 하나도 보여 주지 않는다. 학생이 개인 입장 코드로 자신의 기록을 보는 기존 규칙은 유지한다.

선행 티켓: 없음 — 현재 관리자 화면의 접근 규칙을 수정하는 티켓이다.

Status: ready-for-agent

## 완료 기준

- [ ] 선생님 화면을 열려고 하면 관리자 비밀번호 입력 화면이 보인다.
- [ ] 비밀번호를 입력하기 전에는 학생 목록, 학생 글, 제출 상태, 피드백 입력 영역과 수업 설정 등 선생님 전용 내용이 하나도 보이지 않는다.
- [ ] 비밀번호를 비우거나 틀린 비밀번호를 입력하면 관리자 화면은 열리지 않고, 비밀번호를 확인하라는 안내가 보인다.
- [ ] `teacher-demo`를 입력하면 선생님 화면이 열리고 기존 선생님 화면 내용이 보인다.
- [ ] 학생 코드로 입장하면 해당 학생의 기록만 보이고, 관리자 비밀번호 확인 없이 선생님 전용 내용은 보이지 않는다.

## 범위

관리자 화면의 비밀번호 입력과 확인, 확인 전 내용 숨김만 구현한다. 다른 티켓의 기능은 변경하지 않는다. 테스트 도구를 설치하지 않고 브라우저에서 직접 확인한다.
