# 생각 노트 사용 방법

## 선생님

1. ‘선생님’ → ‘새 수업 만들기’를 누릅니다.
2. 수업 이름, 8자 이상의 비밀번호, 네 가지 질문을 확인합니다.
3. 학생에게 사이트 주소와 수업 코드를 알려 줍니다. 선생님 비밀번호는 알려 주지 않습니다.
4. ‘학생 노트’에서 이름을 선택해 답변을 읽습니다. 각 차수 아래에서 피드백을 저장합니다.
5. 학생이 확인 번호를 잊으면 해당 학생의 ‘확인 번호’를 열어 학생 본인에게만 알려 줍니다.
6. 기록을 더 보관할 필요가 없으면 ‘수업 삭제’로 모든 기록을 함께 삭제합니다.

수업 코드와 비밀번호를 따로 보관하세요. 나갔다가 기존 수업에 다시 들어올 때 필요합니다.

## 학생

1. 선생님이 알려 준 수업 코드와 내 이름을 적고 처음 참여합니다.
2. 내 개인 확인 번호 12자리를 안전한 곳에 적어 둡니다. 다른 친구에게 알려 주지 않습니다.
3. 1번 질문에는 꼭 답합니다. 2~4번은 선택입니다.
4. 제출한 답변과 선생님 피드백을 읽고 ‘2차 답변 쓰기’로 생각을 다듬습니다.
5. 다시 들어올 때는 ‘개인 확인 번호로 들어오기’에서 수업 코드와 확인 번호를 입력합니다. 이름만으로 처음 참여하면 새 노트가 만들어집니다.

## 기록

1차·2차·3차 이후의 답변과 각 차수의 피드백을 모두 보관합니다. 선생님이 질문을 바꾸면 이전 답변에는 기존 질문이 남고, 새 제출에는 새 질문이 적용됩니다. 수업을 삭제하면 이름·개인 확인 번호·답변·피드백·접속 기록이 함께 삭제됩니다.

한 브라우저에서는 한 역할로 접속합니다. 학생과 선생님을 동시에 시험하려면 별도 브라우저나 비공개 창을 사용하세요. 접속은 하루 뒤 다시 확인 번호나 비밀번호로 들어와야 하며 수업 기록은 직접 삭제할 때까지 남습니다.
